## Known Limitations (deferred, not blockers)

1. **mutant + `module_function` quirk:** On demo/fixed-tests, mutant kill rate (1.75%) is slightly LOWER than weak-tests baseline because mutant patches instance methods but tests call singleton methods. Documented in Phase 5 SUMMARY. The LLM mutation report shows the correct improvement (13/13 → 100%) and that's the narrative anchor.
2. **CI annotation:** `ruby/setup-ruby@v1` had a warning about `ruby-version-file` in early Phase 1 commits. Fixed during Phase 2 by switching to explicit `ruby-version: 3.4.9`. Non-blocking; documented.
3. **Subagent classifier for public-surface creation:** Encountered in Phase 1 Wave 4 — gh repo create blocked from subagent context. Workaround documented (run from orchestrator with user-authorized scope). Pattern flagged for future planning.
4. **SKILL-V2-* features explicitly deferred** per REQUIREMENTS.md: coverage-gap-targeted selection, configurable cap, equivalence detection, CI integration. Future enhancements only.
